# Product Requirements Document

Replace this file with your product requirements. This repository is a
**starter template**, not a product.

## What this template already provides

- Bilingual PWA (Hebrew RTL default, English LTR) with language and color-scheme
  switches
- NestJS health API (`GET /health` and `GET /api/health`) over Prisma/PostgreSQL
- Shared Zod contracts and Orval-generated React Query clients
- Example TanStack Query persistence for a generic `items` query key
- Atomic UI package with Storybook
- CI, CodeQL, Dependabot, Release Please, and free-tier deploy workflows

## What you should write here

1. **Problem** — who the users are and what job the app does
2. **Roles** — who can do what
3. **Goals and non-goals**
4. **Core user flows**
5. **Phasing and success metrics**

Keep examples in this document fake. See [ADR 0007](./adr/0007-no-personal-data-in-repo.md).

## Skeleton product (shipped)

The home screen shows translated welcome copy and a live API/database health
card. Treat that as a wiring example. Remove or replace it when your first
feature lands.
